# wish: recognize known branded-string domain aliases as string

## .what

the metadata extractor should recognize a family of known branded-string type aliases and extract each as `STRING` (stored in a string column). today each unrecognized alias falls through to `REFERENCE { of: '<Name>' }`, which breaks downstream codegen.

as part of this, replace the legacy `uni-time` aliases with their `iso-time` equivalents.

## .recognized aliases → STRING

| source | aliases |
|--------|---------|
| serde-fns | `Serializable` |
| uuid-fns | `Uuid` |
| hash-fns | `Hash` |
| iso-price | `IsoPrice`, `IsoPriceWords`, `IsoPriceHuman` (store as the `'USD 50.37'` words form) |
| iso-time | `IsoTimeStamp`, `IsoDateStamp`, `IsoMonthStamp`, `IsoYearStamp`, `IsoTimeFloat`, `IsoHourFloat`, `IsoMinuteFloat`, `IsoMonthFloat`, `IsoDayFloat`, `IsoWeekdayFloat`, `IsoDuration`, `IsoDurationWords` (store durations as the words form) |

### out of scope (object shapes → keep as REFERENCE)

`IsoPriceShape`, `IsoTimeStampRange`, `IsoDateStampRange`, `IsoDurationShape`

### replace uni-time with iso-time

- drop `UniDateTime` / `UniDate` recognition entirely
- swap the uni-time test asset (`NutrientResearchPublicationEvent.ts`) + hydrate test/snapshot to iso-time
- remove the `@ehmpathy/uni-time` devDependency

## .decisions (wisher, 2026-07-22)

- iso-time breadth: **all branded-string types** → STRING, incl. `IsoDuration`/`IsoDurationWords` stored as their words form; object shapes out of scope
- iso-price: `IsoPrice` + `IsoPriceWords` + `IsoPriceHuman` → STRING; `IsoPriceShape` out of scope
- uni-time: **remove** recognition (not kept for back-compat)
- fixtures: add real devDependencies (`iso-time`, `iso-price`, `uuid-fns`, `hash-fns`) and import the true types; remove the uni-time devDep. ~~`Serializable` stays a local fixture decl — serde-fns is not added.~~ **superseded 2026-07-23 (see override below).**

## .decisions (wisher, 2026-07-23 — override)

- serde-fns **is** added: `serde-fns@1.3.1` is a real pinned devDependency, and `SeaTurtleAliasZoo.ts` imports the true `Serializable` from it (in place of the local `type Serializable = …` decl). this reverses the 2026-07-22 "serde-fns is not added" call — it makes the fixture consistent with the other four packages (`iso-time`, `iso-price`, `uuid-fns`, `hash-fns`), and extraction output is unchanged (match is name-based, not import-source-based). so **five** real devDependency additions, not four.

## .representation (wisher, 2026-07-22)

each recognized alias extracts as **both** its storage primitive and its brand — not a bare primitive that forgets what it was:

```ts
{ type: 'ALIAS', of: { name: 'Uuid', primitive: 'STRING' } }
```

uses the reserved-but-idle `ALIAS` property type. the `of: { name, primitive }` shape matches what `extractAliasMetadataFromAliasDeclaration` already returns.

## .acceptance

- **core**: every recognized alias is exhaustively covered by its own **divergent seaturtle-themed** test fixture — one distinct sea-world entity per alias, no alias proven by proxy
- **core**: all fixtures are **fully snapshotted** (each extraction + hydration result captured in a snapshot for visual spotcheck)
- each alias extracts as `{ type: 'ALIAS', of: { name, primitive: 'STRING' } }`, with nullable/required preserved and arrays → ARRAY of ALIAS
- `UniDateTime`/`UniDate` no longer recognized; iso-time equivalents recognized in their place
- devDependency swap applied (uni-time out; iso-time, iso-price, uuid-fns, hash-fns in)
