# wish: support primitive arrays as json/text column

## .what

extract primitive arrays (`string[]`, `number[]`, etc.) as a json/text column for schema generation. today only arrays of domain objects are supported.

```ts

```

- extracts as a primitive-array shape (json/text), nullable/required preserved
- prior domain-object-array behavior unchanged
